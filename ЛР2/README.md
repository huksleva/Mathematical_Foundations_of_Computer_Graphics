## Тема

**«Выход в трехмерный мир»** по книге Пола Орланда
«Математические алгоритмы для программистов. 3D-графика, машинное обучение и моделирование на Python».

## Содержание

В Jupyter Notebook выполнены упражнения **3.1–3.28** главы 3:

- отображение трехмерных векторов;
- построение куба;
- сложение, вычитание и масштабирование векторов;
- вычисление длин и расстояний;
- углы и направления;
- скалярное произведение;
- векторное произведение;
- проверка перпендикулярности;
- построение ребер октаэдра;
- проекция трехмерных граней на плоскость;
- определение видимых граней;
- простое затенение трехмерного объекта.

## Используемые библиотеки

- Python 3.10+
- NumPy
- Matplotlib
- Jupyter Notebook

## Установка

В активированном виртуальном окружении выполнить:

```bash
python -m pip install -e .
```

Либо установить зависимости напрямую:

```bash
python -m pip install numpy matplotlib jupyter ipykernel
```

## Запуск

Из каталога `ЛР2`:

```bash
jupyter notebook
```

После запуска открыть файл:

```text
LR2_Глава_3_Выход_в_трехмерный_мир.ipynb
```

Для проверки всех решений можно выполнить:

**Kernel → Restart Kernel and Run All**
